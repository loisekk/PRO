<li>Sandboxed execution for untrusted tool calls</li>
<li>A reproducible harness for evaluating agent behavior</li>
</ul>
<b>Measured by</b> &nbsp;·&nbsp; <sub>task success rate · steps per task · recovery rate</sub>
